# Проверка просмотра чертежей ПИР

Модуль открывает загруженные PDF, PNG, JPEG и WebP внутри приложения. Каждый штрих автоматически сохраняется без обязательного замечания, с номером страницы, ID версии файла, автором и временем. Админка и мобильный просмотр обновляют общую разметку каждые пять секунд в активном экране. Возможность разметки определяется серверным `can_annotate`; при отсутствии поля доступен просмотр. Текстовое замечание сохраняется отдельно.

Для нативной проверки нужен Android-эмулятор и тестовый PDF из трёх страниц. Включите обычный лист, лист с поворотом 90° и большой лист A0. Используйте тестовые данные, без документов заказчиков.

```powershell
adb -s <device> push <fixture.pdf> /data/local/tmp/most-pir-drawing-20261013.pdf
$env:DRAWING_QA_OUTPUT_DIR = '<каталог вне checkout>'
flutter drive --driver=test_driver/drawing_viewer_driver.dart --target=integration_test/drawing_viewer_device_test.dart -d <device>
```

Проверка использует настоящий PDF-движок и тестовые ответы сервисов разметки и замечаний. Проверяются открытие трёх страниц, рисование стрелки, автоматическое сохранение номера страницы и штриха без текста, отдельное замечание без дублирования рисунка и переход на повёрнутый лист. «Сохранить и выйти» ждёт отложенной отправки штриха второго листа, после подтверждения закрывает просмотр. Скриншоты сохраняются вне репозитория. Серверное сохранение, права и совместимость с админкой проверяются отдельными HTTP-тестами backend.

Целевые тесты очереди проверяют повтор с прежним UUID, курсор только из GET, отсутствие возврата отменённого штриха при позднем ответе, запрет удаления чужой разметки и остановку при смене сессии. Неподтверждённые рисунки хранятся в памяти экрана; при закрытии без сохранения они могут быть потеряны. Долговременная очередь без сети пока не реализована.

Для выпуска также нужны анализ изменённых файлов, целевые тесты ПИР и полный набор Flutter-тестов. Подписанный AAB собирается штатным workflow после merge в main; отправка в RuStore требует проверки SHA-256 точного CI-артефакта.
